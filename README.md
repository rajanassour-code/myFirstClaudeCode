# Live Video Assist — Flutter SDK + Cedar Bank demo

- `flutter/live_assist` — the SDK (pure Dart, uses `flutter_webrtc`): video call, chat, co-browse with masking and assisted control.
- `flutter/demo_bank` — Cedar Bank demo app wired to https://video.rajanassour.com
- The workflow builds `CedarBank-Flutter-demo.apk` and publishes it to the `live-assist-flutter-build` branch.
